# Global Workspace Rules

The following rules must be strictly adhered to by any AI assistants or developers working in this repository:

## Formatting & Domains
1. **Timing:** All timing should be in IST ALWAYS.
2. **Currency:** All currency should be in RS.
3. **Market Hours:** Market timings are 9:00 AM to 3:45 PM IST.

## Development Workflow
4. **Commenting:** ALWAYS add comments while changing even a single line of code.
5. **Analysis Phase:** ALWAYS do a proper RCA (Root Cause Analysis) before writing code.
6. **Permission to Code:** Once you share the RCA and fix plan, ASK FOR PERMISSION before changing any code.
7. **Permission to Push:** At the end of the task, ASK PERMISSION to push to Git.
8. **Stale Changes:** Before starting anything new, ask the admin to confirm whether to push old changes (if there are any uncommitted) before starting fresh.
9. **Git Commits:** Make sure to add full, comprehensive details in the Git commit message.
